## 1. Общие сведения

**Наименование проекта:** GORGON

**Назначение:**
Система предназначена для фильтрации, мониторинга и управления трафиком в оверлейной сети TOR с целью повышения безопасности, выявления аномалий и предотвращения несанкционированной деятельности.

**Область применения:**
GORGON применяется в инфраструктурах, где требуется контроль и анализ трафика TOR, в том числе в корпоративных, исследовательских и государственных сетях.

## 2. Основания для разработки

- Необходимость обеспечения безопасности при работе с анонимными сетями.
- Требования по контролю и фильтрации трафика TOR.

## 3. Архитектура системы

### 3.1. Общая структура

Система состоит из следующих основных компонентов:
- **Модуль фильтрации трафика** (filter/): реализует фильтрацию пакетов с использованием eBPF/XDP и tc.
- **Модуль сбора и анализа мостов TOR** (bridge-harvester/): автоматизированный сбор актуальных мостов TOR.
- **Модуль управления инфраструктурой** (infra/): автоматизация развертывания и управления инфраструктурой с помощью Ansible и Terraform.
- **Модуль логирования** (logger/): централизованный сбор и хранение логов событий.
- **Модуль оповещений** (alert.go, telegram-alert.sh): уведомление операторов о событиях.

### 3.2. Взаимодействие компонентов

1. **Фильтрация трафика** осуществляется на уровне ядра с помощью eBPF/XDP и tc-фильтров, реализованных в директории `filter/`.
2. **Сбор мостов TOR** выполняется скриптами Python (`bridge-harvester/fetch_bridges.py`), результаты сохраняются в `ips/bridge_nodes.txt`.
3. **Инфраструктурное управление** реализовано через Ansible (`infra/ansible/`) и Terraform (`infra/tf/`).
4. **Логирование** событий и действий осуществляется через модуль `logger/`.
5. **Оповещения** о критических событиях отправляются через Telegram-бота (`telegram-alert.sh`).

## 4. Описание компонентов

### 4.1. Bridge Harvester (bridge-harvester/): Микросервис на Python, осуществляющий автоматизированный сбор актуальных узлов и скрытых мостов TOR (с использованием алгоритмов имперсонации браузера через Selenium).

### 4.2. eBPF Filter & Manager (filter/): Управляющее приложение на Go. Компилирует XDP-байткод, загружает обновленные IP-адреса в BPF-карты (Hash Maps) и атомарно обновляет правила фильтрации без прерывания обработки трафика.

### 4.3. Logger & Alerter: Подсистема журналирования, генерирующая логи по стандарту RFC 5424. При обнаружении критических аномалий отправляет алерты администраторам через Telegram Bot API.

### 4.4. Infrastructure (infra/): IaC-манифесты (Terraform и Ansible) для автоматизированного развертывания VPC, настройки WireGuard и подготовки среды исполнения на серверах.

## 5. Требования к программному и аппаратному обеспечению

- ОС: Linux (рекомендуется Ubuntu 20.04+)
- Ядро: с поддержкой eBPF/XDP
- Python 3.8+
- Go 1.18+
- Docker, Docker Compose
- Ansible, Terraform

## 6. Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/sagilyp/GORGON.git
   cd GORGON
   ```
2. Собрать и запустить контейнеры:
   ```bash
   docker-compose up --build
   ```
3. Настроить переменные окружения и конфигурационные файлы согласно документации в `infra/`.
4. Запустить сбор мостов TOR:
   ```bash
   cd bridge-harvester
   ./run-fetch-bridges.sh
   ```
5. Запустить фильтрацию трафика:
   ```bash
   go run main.go
   ```
